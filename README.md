# ⭕ Tic-Tac-Toe vs AI

Game tic-tac-toe di browser melawan AI. Kamu bermain sebagai **X**, AI sebagai **O** dan menggunakan algoritma **minimax** — jadi AI selalu berusaha menang atau memblokir langkahmu.

## Fitur

- 🤖 AI minimax: mengejar kemenangan sendiri, memblokir kemenangan pemain
- 📊 Papan skor **Menang / Kalah / Seri** selama sesi
- ✨ Garis kemenangan disorot saat permainan berakhir
- 🔄 Tombol **Main Lagi** untuk ronde baru

## Cara menjalankan

Cukup buka file-nya di browser:

```bash
cd tictactoe-ai
xdg-open index.html        # Linux
# atau: open index.html    # macOS
# atau klik dua kali file index.html di file manager
```

Alternatif dengan server lokal:

```bash
python3 -m http.server 8000
# buka http://localhost:8000
```

## Tips

Mainkan dengan sempurna dan kamu hanya akan seri — AI minimax tidak bisa dikalahkan! 😄
